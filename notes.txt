ENDPOINTS
---------
POST   /auth/users/                              register (username, email, password)
POST   /auth/token/login/                        get token
GET    /auth/users/me/                           current user
GET    /api/categories                           any authenticated user
POST   /api/categories                           admin only
GET    /api/menu-items                           all roles (?page= ?ordering=price ?category=1 ?category__title=Main ?search=pasta)
POST   /api/menu-items                           admin or manager
GET    /api/menu-items/{id}                      all roles
PUT/PATCH/DELETE /api/menu-items/{id}            admin or manager ({"featured": true} = item of the day)
GET/POST /api/groups/manager/users               admin only
DELETE /api/groups/manager/users/{userId}        admin only
GET/POST /api/groups/delivery-crew/users         admin or manager
DELETE /api/groups/delivery-crew/users/{userId}  admin or manager
GET/POST/DELETE /api/cart/menu-items             customers
GET    /api/orders                               customer: own / manager: all / delivery crew: assigned
POST   /api/orders                               customer (creates order from cart)
GET    /api/orders/{orderId}                     owner, manager, or assigned delivery crew
PUT/PATCH /api/orders/{orderId}                  manager: delivery_crew + status / delivery crew: status only
DELETE /api/orders/{orderId}                     manager or admin

THROTTLING
----------
/api/menu-items and /api/categories: anonymous 5/minute, authenticated 10/minute
(rates in LittleLemon/settings.py -> REST_FRAMEWORK['DEFAULT_THROTTLE_RATES']).
If you get HTTP 429, wait one minute.
